# examples

Chainkit integration examples.

## Scope and boundaries

- Show applications how to adopt modules through published dependencies.
- Demonstrate configuration, Makefile entry points, and module collaboration.
- State the dependency versions and runtime requirements for each example.
- Keep examples focused; shared implementations belong in packages.
- Do not include real keys or other credentials.

The first example, [multi-project contract indexing](contract-indexer/README.md), provides operator configuration and application Makefile entry points.
